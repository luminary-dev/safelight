# ADR 0002 — Source-available under BSL 1.1

Safelight is a commercial Luminary product with a privacy promise, so the source stays
readable while hosted-competitor use is restricted: Business Source License 1.1, change date
2030-09-26, change license Apache-2.0, with an Additional Use Grant covering personal and
internal production use. Revisit before 1.0 alongside the business-model decision
(brief Workstream W); this choice is reversible while there are no external contributors.
